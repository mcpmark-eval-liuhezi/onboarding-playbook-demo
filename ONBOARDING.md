# Contributor Onboarding Guide

Welcome! This checklist takes you from clone to your first merged pull request.

## 1. Repository layout
- [ ] Read the README and skim the docs/ folder
- [ ] Find the CI workflow under .github/workflows/

## 2. Local dev setup
- [ ] Clone the repository and create a feature branch
- [ ] Install dependencies and run the full test suite once

## 3. Code review norms
- [ ] Open a draft pull request early to get feedback
- [ ] Keep pull requests small and reply to every review comment
